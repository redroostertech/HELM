### FAQ

**Q: Can I use HELM without paying?**
A: Yes. The free tier gives you a full terminal with multi-tab support, command history, session recording, and 5 AI requests per month. No credit card required.

**Q: What counts as an AI request?**
A: Each chat message, command explanation, or command suggestion counts as one AI request.

**Q: What's the difference between BYOK and Basic/Pro?**
A: BYOK lets you use your own OpenAI or Anthropic API key for unlimited AI requests at $2.99/month. Basic and Pro use HELM's built-in AI — no API key needed — with monthly request limits.

**Q: Can I switch plans at any time?**
A: Yes. Upgrade, downgrade, or cancel at any time. Changes take effect immediately.

**Q: Do you store my terminal data?**
A: Your command history and session data are stored locally on your machine in a PostgreSQL database. HELM does not send your terminal data to any server. AI requests send only the specific command or question to the AI provider.

**Q: What AI models does HELM use?**
A: HELM uses OpenAI's GPT-4o Mini by default. BYOK users can choose from GPT-4o, GPT-4 Turbo, Claude Sonnet 4, Claude Haiku 4.5, or Claude Opus 4.

**Q: Is HELM available on Windows or Linux?**
A: HELM is currently macOS only (Apple Silicon and Intel). Windows and Linux support is on the roadmap.

### Installation Steps

**Step 1: Download**
Click the button above to download the HELM .dmg file.

**Step 2: Install**
Open the .dmg and drag HELM to your Applications folder.

**Step 3: Setup Database**
Open Terminal and run:
```
brew install postgresql@16
brew services start postgresql@16
createdb helm
```

**Step 4: Launch**
Open HELM from Applications. Your terminal is ready.

**Step 5: (Optional) Add Your API Key**
Click the settings gear in the tab bar. Choose your AI provider and paste your API key for unlimited AI requests. Or just use the 5 free requests to try it out.
